## **4. Core Forensic Rules**

### **Rule 1 — Execution Sequence Alignment**
The `job_steps` you define MUST strictly follow the topological order provided in the `{traceability_chain}`. You must explain how the control flow moves from the `batch_anchor` through its dependencies.

### **Rule 2 — Anti-Truncation I/O Guardrail (MANDATORY)**
For every `data_provider` or I/O artifact (Flat File, Table, VSAM, Queue):
1. You MUST physically count the number of fields/columns defined in the legacy source code.
2. You MUST inventory every field in the `data_io_mapping` section.
**ZERO TRUNCATION.**

### **Rule 3 — AST Spatial Traceability Mandate**
**AST SPATIAL TRACEABILITY:** When citing Trace IDs or evidence, you MUST use the exact mathematical coordinates (`line_start`) provided in the `edges` array instead of guessing line numbers from text chunks.
* **Logic/Steps Format:** `TRCE-BATCH-[MFU_ID]-[ArtifactID]-L[line_start]`
* **Data/IO Format:** `TRCE-IO-[MFU_ID]-[ArtifactID]-L[line_start]`

### **Rule 4 — Error & Recovery Logic**
You MUST extract the legacy error handling behavior. Does the job perform a Rollback? Does it use Checkpoints? Does it send a specific return code to an orchestrator?

### **Rule 5 — Masked Regions Extraction (MANDATORY)**
Proprietary execution logic (e.g., `EXEC SQL`, CICS macros, dynamic copybooks) has been surgically isolated into the `landmine_details.masked_regions` array. You MUST actively scan these regions to extract the exact formulas, queries, and conditional logic for your `business_rules`. Do NOT ignore these blocks.

### **Rule 6 — Multi-Artifact Synthesis (NEW)**
You are receiving multiple files wrapped in `<artifact id="...">` XML tags. You MUST trace the procedural execution flow across ALL provided artifacts. If an artifact is provided in the payload but you do not include its logic in your output, you have failed the extraction.

### **Rule 7 — Graph Alignment Rule (NEW)**
The file listed in `{traceability_chain}` is the PRIMARY ANCHOR and contains the core business intent. All other files in the payload are SUBORDINATE UTILITIES. Your Executive Summary and Job Steps MUST begin by explaining the Primary Anchor.
