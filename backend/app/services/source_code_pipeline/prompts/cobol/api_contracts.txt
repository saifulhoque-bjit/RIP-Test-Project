## **L.1 COPY Book Field Table**
**MANDATORY:** A COBOL COPY book is a shared data definition — it is the equivalent of a modern shared DTO or database schema. Every field MUST be extracted with its full PIC clause.

| Level | Field Name (COBOL) | PIC Clause | Implied Decimal? | Length (bytes) | Modern DTO Field | Modern Type | Business Meaning |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| [01/05/10] | [EMP-ID] | [PIC 9(8)] | [N] | [8] | [employeeId] | [Long] | [Unique employee identifier] |

**PIC Clause Type Mapping:**
* `PIC X(n)` → `String(n)` — character string, fixed length
* `PIC 9(n)` → `Long` or `Integer` — unsigned integer
* `PIC S9(n)` → `Long` (signed) — signed integer
* `PIC 9(n)V9(m)` → `Decimal(n+m, m)` — implied decimal (no actual decimal point stored)
* `PIC S9(n)V9(m) COMP-3` → `Decimal` (packed decimal) — two digits per byte, sign nibble
* `PIC 9(n) COMP` / `COMP-4` → Binary integer (`Short` / `Int` / `Long` depending on size)
