**MANDATORY:** Long-running COBOL batch jobs frequently implement checkpoint and restart logic to avoid reprocessing from the beginning after an abend. This pattern MUST be documented because it defines the job's resiliency contract.

| :--- | :--- | :--- | :--- | :--- | :--- |

**Key Items to Capture:**
* **`COMMIT WORK` Frequency:** Identify how often `EXEC SQL COMMIT WORK END-EXEC` is issued within a loop — this defines the unit of work for rollback granularity.

* **SYSIN / PARM Parameters:** Identify JCL `SYSIN` or `PARM` data that passes the restart key or checkpoint frequency as a runtime parameter.
* **Checkpoint File Layout:** If a sequential checkpoint file is used, extract its record layout — this is a restart contract artifact.
