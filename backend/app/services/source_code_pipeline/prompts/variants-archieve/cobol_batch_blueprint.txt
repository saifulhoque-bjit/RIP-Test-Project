* **PERFORM UNTIL:** Extract the exact condition (`UNTIL WS-EOF = 'Y'`) — this is the batch loop termination logic.

* **GO TO:** Flag every `GO TO` statement — these are unstructured control transfers that require special handling in modern structured code.
* **EVALUATE (COBOL CASE):** Extract every `WHEN` branch in `EVALUATE` statements — these are the routing decisions in the processing logic.

* **COMMAREA Contract:** Document the COMMAREA layout used in `EXEC CICS LINK/XCTL` calls — this is the inter-program data contract and maps to a modern service request/response DTO.

* **SELECT INTO:** These are single-row lookups — document the target host variables.
